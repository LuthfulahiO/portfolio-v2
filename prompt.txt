Create a comprehensive web-based AI-powered portfolio website that revolutionizes the traditional developer portfolio experience.

## PROBLEM STATEMENT
Traditional portfolios are static and quickly become outdated. They often fail to provide the specific information recruiters need and lack meaningful interaction capabilities.

## PROJECT VISION
Design an intuitive, modern, and interactive portfolio website centered around an AI chat interface that allows:
- Recruiters to ask direct questions about my skills and experience
- Employers to paste job descriptions and get tailored compatibility analyses
- Potential clients to explore my unique value propositions
- Fellow developers to evaluate my potential as a mentor or collaborator

## CORE FEATURES
1. **AI Chat Interface**
   - Conversational UI that processes natural language queries
   - Ability to understand and respond to complex questions about my experience
   - Support for analyzing job descriptions to highlight relevant skills and experience
   - Capability to generate comparative analyses (tables, charts) when requested

2. **Content & Training Data**
   - Utilize all documents in public/training_data/ including:
     * Multiple resume versions
     * Recommendation letters from previous managers
     * Project case studies and achievements
     * Published articles and technical content
   - Implement OpenAI API integration for processing these materials

3. **User Experience Requirements**
   - Modern, distinctive UI that stands apart from typical chatbot interfaces
   - Responsive design that works flawlessly on all devices
   - Intuitive navigation that guides users toward meaningful interactions
   - Support for rich media responses (tables, diagrams, code snippets) based on query context
   - Option to download standard resume for users who prefer traditional formats
   - Feature to generate and download a customized resume based on the conversation

4. **Implementation Details**
   - Create a compelling intro page with call-to-action to start conversation
   - Build a robust chat interface with appropriate loading states and response handling
   - Implement backend API with OpenAI integration for processing queries
   - Ensure the backend can fine-tune responses using all training materials
   - Add resume download options (both standard and conversation-customized versions)

## TECHNICAL CONSIDERATIONS
- Implement proper handling of different response types (text, tables, comparisons, etc.)
- Ensure the UI communicates response format needs to the backend
- Build with modern web technologies that support interactive elements
- Prioritize performance and response time for a smooth user experience

## DESIGN PHILOSOPHY
The interface should position me in the best possible light while providing genuine value to visitors. The experience should feel premium, thoughtful, and reflective of my skills and attention to detail.

Proceed with implementing both the frontend UI components and the backend API integration with OpenAI, ensuring all features are fully functional and the experience is cohesive.
